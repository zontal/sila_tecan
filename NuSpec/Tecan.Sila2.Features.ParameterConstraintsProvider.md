# Generic support for parameter constraints in the Tecan Sila SDK

## Why should I use this package

Use this package if you want to build a server with support for dynamic parameter constraints.

Parameter constraints are enabled by adding the feature provider to the DI container. In case you are using the default server packages, this is done automatically and just adding the package reference is sufficient for your server to support dynamic parameter constraints
as long as your features define dynamic parameter constraints via metadata.
